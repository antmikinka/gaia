## 6. Instructions for senior-developer

### Immediate Actions Required

1. **Review Quality Report**
   - Read `P3.1_QUALITY_REPORT.md` in full
   - Understand root cause of each defect

2. **Fix DEF-002 (Memory Measurement) - HIGHEST PRIORITY**
   - Location: `gaia/src/gaia/metrics/benchmarks.py:32-43`
   - Issue: `tracemalloc` positioning may be incorrect
   - Expected: Memory readings should reflect realistic Python process usage (20-50MB minimum)
   - Action: Verify tracemalloc start/stop surrounds actual pipeline execution, not just async sleep

3. **Fix DEF-001 (Random Seed) - HIGH PRIORITY**
   - Location: `gaia/src/gaia/metrics/benchmarks.py:276-290`
   - Issue: No seed initialization for reproducible runs
   - Action: Add `random.seed(42)` and `numpy.random.seed(42)` at benchmark initialization
   - Document seed value in benchmark configuration

4. **Fix DEF-004 (Type Hint)**
   - Location: `gaia/src/gaia/metrics/benchmarks.py:477`
   - Change: `scale_levels: List[int] = None` to `scale_levels: Optional[List[int]] = None`

5. **Fix DEF-005 (Memory Leak Logic)**
   - Location: `gaia/src/gaia/metrics/benchmarks.py:87-88`
   - Issue: Endurance test flags `memory_leak_detected: True` but summary says "No bottlenecks"
   - Action: Ensure bottleneck analysis reflects memory leak status accurately

6. **Fix DEF-006 (Environment Metadata) - If Time Permits**
   - Location: `gaia/src/gaia/metrics/benchmarks.py:118-134`
   - Add: CPU model, RAM total, Python patch version

### Handoff to testing-quality-specialist

After senior-developer completes DEF-001, DEF-002, DEF-004, DEF-005:

1. Create `gaia/tests/metrics/test_benchmarks.py`

   - `run_token_efficiency_benchmark`

   - `run_endurance_benchmark`
3. Add reproducibility test (3 consecutive runs, same results)
4. Validate memory measurements against known baselines
