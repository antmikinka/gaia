## Defects Found

### Defect #1: LOW - Memory Delta Calculation Confusion

| Field | Value |
|-------|-------|
| **Severity** | LOW |
| **Type** | Documentation/Measurement |
| **Location** | `scale_test_runner.py`, line 201 |
| **Description** | Memory delta calculation shows negative values due to GC timing between baseline and peak measurements. While documented in the report, the calculation method (`memory_peak_avg - memory_baseline_avg`) can produce confusing results. |
| **Impact** | Potential misinterpretation of memory metrics |
| **Recommendation** | Use tracemalloc peak as primary memory metric, supplement with psutil delta as secondary |
